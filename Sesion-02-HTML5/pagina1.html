Conceptos básicos de HTML

¿Qué es HTML?

HTML es un lenguaje de marcado utilizado para organizar y dar significado al contenido de las páginas web.

Estructura básica de un documento HTML

  1. Declaración del tipo de documento.
  2. Elemento principal HTML.
  3. Encabezado del documento.
  4. Contenido visible dentro del cuerpo.
