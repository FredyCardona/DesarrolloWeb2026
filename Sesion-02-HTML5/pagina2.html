Herramientas de desarrollo web

Editor de código

Un editor de código permite crear y organizar los archivos necesarios para desarrollar un sitio web.

Herramientas utilizadas

  • Visual Studio Code para editar los archivos.
  • Google Chrome para visualizar las páginas.
  • Git para controlar los cambios del proyecto.
  • GitHub para almacenar el repositorio.

Información adicional

Estas herramientas facilitan la creación, prueba y publicación de un proyecto web.
